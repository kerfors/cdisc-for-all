cdisc-for-all

CDISC and NCIt content as published, linked. For study design: what is defined about a lab test, and why, before any data is captured.

A lab test in SDTM Controlled Terminology has an NCIt concept. CDISC COSMoS describes the same concept as a Biomedical Concept (BC): what has to be specified to measure it, and the variants in which it is used. cdisc-for-all links these published sources, so that one page shows them together, each value as its source publishes it.

How to read a page

SDTM CTNCItCOSMoS BCCOSMoS Dataset Specialization

Columns from left to right: the test, its NCIt concept, the BC (with its parents), the BC's Data Element Concepts, and the bound CT terms. Each box is a row of a published table or an NCIt concept; each line is a link. Click a box to see every published value of it under its published column name; click a line to see which link it is. A dashed line is a test reached through a Specialization rather than through the shared NCIt concept.

How the sources link

The link map shows every link between the source tables, as stated: its key columns, its rule where it rests on one, and its rows in Link_Check, where the published content does not resolve.

Your own test

Any SDTM CT test term, by its C-code, with Python (the commands in the README):

python examples/test_concept.py C105585

What it is built on

COSMoS (latest export), SDTM Controlled Terminology, the NCI Thesaurus and its code–CUI map, the Non-Standard Variable Registry, and the SDTMIG and SDTM Model variable tables (cdisc.org sign-in, used locally only). Every value is as published; links rest on published keys or on stated rules; every reference that does not resolve is listed in Link_Check. Source, rules and pins: github.com/kerfors/cdisc-for-all.

Not an official CDISC or NCI product. The content stays under the terms of its publishers (see the README).
