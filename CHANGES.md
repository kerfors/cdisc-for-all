# Changes

## Step 1 — the contract and the NSV Registry base graph (2026-11-26)

**Code.** The base mapping rule is stated as W3C CSV on the Web (CSVW) metadata: one table description per source table, generated from the source's LinkML module, which stays the one hand-kept description. `cfa` holds the shared helper: the pin check against Reference_Versions.json; text readers (xlsx with the OOXML escape `_xHHHH_` decoded, CSV per RFC 4180, TSV without quote handling); the IRIs; the generator of CSVW descriptions; our implementation of CSVW minimal-mode conversion for the subset used (an empty key component gives an empty path segment, an empty cell gives no triple, a quoted empty value and a missing value are the same); the longturtle writer; the graph hash (SHA-256 of canonical N-Triples); the Excel view writer (every cell text); the text hash (SHA-256 of the table as a JSON array, rows sorted by key); the Schema sheet; Provenance.json. Structural SHACL is generated by LinkML gen-shacl. `checks/00_Schema` checks the modules against the rule, generates the CSVW descriptions and the SHACL shapes, and tests the tools on fixtures. `checks/CSVW_Crosscheck` converts each base table with rdf-tabular, the reference CSVW implementation, and requires the same graph.

**Content.** The first base graph: the NSV Registry sheet "Approved NSVs-alpha", as published, with its Excel view and Provenance. The view rebuilt from the graph has the text hash of the source table: the graph is lossless.
